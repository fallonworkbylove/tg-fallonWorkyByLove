LoveRussian OPS — установка (Windows / Mac)

Что это
  Кабинет вне Telegram: воронка, аккаунты, управление, логи (фото/кружок/NFT), обновления.
  Все живые данные и логи идут с сервера. Один ключ доступа = тот же кабинет, что у команды.

WINDOWS
1) LoveRussian-OPS-*-win-x64.exe — установщик
   или LoveRussian-OPS-*-portable.exe — без установки
2) Запусти программу
3) Настройки → вставь ключ доступа (тот же ADMIN_CONSOLE_TOKEN, что у команды) → «Сохранить и войти»
4) Готово: воронка, аккаунты и вкладка «Логи» как на сервере

MAC
1) Распакуй LoveRussian-OPS-*-mac-*.zip
2) Перенеси «LoveRussian OPS.app» в Applications
3) Первый запуск: ПКМ → Открыть
   (если блок: xattr -cr "/Applications/LoveRussian OPS.app")
4) Настройки → ключ доступа → «Сохранить и войти»

Важно
- Ключ в установочный файл НЕ кладётся — каждый вводит у себя один раз.
- Не кидай ключ в чаты и публичные архивы.
- Адрес кабинета по умолчанию: https://loverussian.duckdns.org
- Дополнительно можно положить config.json рядом с программой
  (см. config.example.json) — но проще через Настройки.
