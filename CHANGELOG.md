# Changelog

## 2026-09-12

### Исправления

- Исправлена отправка фотографий из медиа-канала Telegram по ссылке.
- Добавлена поддержка ссылок `t.me`, `telegram.me`, `@username`, приватных `+hash` и ссылок формата `t.me/c/...`.
- Добавлена серверная проверка ссылок медиа-каналов.
- Добавлена обработка недоступных или удалённых медиа-сообщений.
- Исправлены повреждённые строки в интерфейсе.
- Уведомления теперь отправляются всем подписчикам уведомляющего бота, у которых есть хотя бы один привязанный Telegram-аккаунт.
- Исключены пользователи без привязанных аккаунтов из списка получателей уведомлений.

### Технические изменения

- Обновлены сервисы Telegram-медиа и уведомлений.
- Добавлены проверки синтаксиса изменённых backend-модулей.
- Изменения объединены в Pull Request из ветки `v0/fix-media-channel` в `repository-file-list`.
