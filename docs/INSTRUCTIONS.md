# Инструкции

## 1. Обновление сервера (после исправлений от аудита)

Ветка с исправлениями: `v0/bugfix-audit`.

Если хочешь **сразу применить фиксы** (до того как ветку смержат в `repository-file-list`):

```bash
cd /root/opt/tgbot/tg-miniapp-loverussian/
git fetch origin
git checkout v0/bugfix-audit
git pull origin v0/bugfix-audit
pm2 restart all
```

Если ветка уже смержена в основную и нужно обновиться как обычно:

```bash
cd /root/opt/tgbot/tg-miniapp-loverussian/
git checkout repository-file-list
git pull origin repository-file-list
pm2 restart all
```

Проверить, что бот поднялся без ошибок:

```bash
pm2 status
pm2 logs --lines 50
```

Если в логах сразу после `pm2 restart all` есть красные `Error` / `ECONNREFUSED` / `SyntaxError` — значит что-то не так, нужно смотреть лог подробнее и не считать обновление завершённым.

## 2. Инструкция для оператора бота

**Что проверять после каждого обновления:**

1. Открыть панель управления (мини-апп) — убедиться, что дашборд и статистика открываются без ошибки (белый экран / "Ошибка загрузки" — сигнал, что backend не поднялся).
2. Проверить, что аккаунты в списке аккаунтов в статусе "онлайн"/"активен", а не "ошибка"/"отключен".
3. Написать тестовое сообщение боту с любого аккаунта и убедиться, что ответ приходит в течение обычного времени (не мгновенно — у бота есть эмуляция "печатает...", это нормально).

**Если бот не отвечает:**
- Проверить в панели, что аккаунт не заблокирован Telegram (статус аккаунта).
- Проверить, что собеседник не попал в чёрный список (раздел "Чёрный список" в панели) — таким людям бот не отвечает специально.
- Если аккаунт "спит" по времени (ночной режим) — это ожидаемое поведение, бот не отвечает ночью по настройке тайм-стиля.

**Голосовые сообщения:**
- Если оператор просит бота выслать голосовое (просьба о помощи с NFT/токеном) — уведомление придёт отдельным сообщением от бота-нотификатора с кнопкой "Открыть приложение". Не нужно вручную искать диалог — кнопка ведёт прямо в нужный чат в панели.
- Повторно то же голосовое одному и тому же собеседнику бот теперь не отправляет (это защита от дублей) — если голосовое нужно отправить снова, это делается вручную через панель, а не жди, что бот пришлёт его сам второй раз.

**Чёрный список:**
- Добавлять туда тех, с кем общение нужно прекратить — бот сразу перестанет отвечать этому собеседнику на всех аккаунтах.

**Если что-то выглядит странно (бот повторяется, путает факты, отвечает не в тему):**
- Не нужно чинить это самостоятельно правкой промптов на сервере — сообщить разработчику с примером диалога (скрин или текст переписки), это используется для дальнейшего обучения бота.
