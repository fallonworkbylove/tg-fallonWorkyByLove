# Список прокси для Telegram-клиента.
# Скопируй этот файл в proxies.txt (или укажи свой путь через PROXY_FILE в .env)
# и заполни реальными прокси — по одной записи на строку.
#
# Формат (тот же, что в PROXY_LIST, но без ";" — разделитель здесь просто перевод строки):
#   mtproxy:IP:PORT:SECRET
#   socks5:IP:PORT
#   socks5:IP:PORT:USER:PASS
#
# Строки, начинающиеся с "#", и пустые строки игнорируются.
#
# Примеры (замени на свои):
# mtproxy:1.2.3.4:443:ee00aa11bb22cc33dd44ee55ff66aa77
# socks5:9.9.9.9:1080:myuser:mypass
